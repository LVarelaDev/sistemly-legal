# Sistemly · información legal

Páginas públicas que Meta exige para la app de WhatsApp de Sistemly: política de privacidad, condiciones del servicio y eliminación de datos.
Se publican con GitHub Pages desde la rama `main`.

- `index.html`: portada
- `privacidad.html`: política de privacidad
- `terminos.html`: condiciones del servicio
- `eliminacion-de-datos.html`: cómo pedir la eliminación de datos
- `icon-1024.png`: ícono de la app
